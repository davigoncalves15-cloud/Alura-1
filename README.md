# 🌐 Portfólio Web Alura

Um website portfólio moderno e responsivo, desenvolvido do zero com HTML5, CSS3 e JavaScript puro.

## ✨ Características

- ✅ **Design Responsivo** - Funciona perfeitamente em desktop, tablet e mobile
- ✅ **Navegação Inteligente** - Menu hamburger para dispositivos móveis
- ✅ **Animações Suaves** - Transições elegantes e efeitos visuais
- ✅ **Formulário de Contato** - Validação de dados em tempo real
- ✅ **Performance Otimizada** - Código limpo e otimizado
- ✅ **SEO Friendly** - Estrutura semântica e meta tags
- ✅ **Acessibilidade** - Cores contrastantes e navegação por teclado

## 📁 Estrutura de Arquivos

```
Alura-1/
├── index.html          # Página principal (HTML)
├── styles.css          # Estilos globais (CSS)
├── script.js           # Lógica interativa (JavaScript)
└── README.md           # Documentação
```

## 🎨 Seções do Website

1. **Navegação** - Menu fixo com links para todas as seções
2. **Hero Section** - Seção de boas-vindas com destaque principal
3. **Sobre** - Informações pessoais e barra de habilidades
4. **Serviços** - Cartões com serviços oferecidos
5. **Portfólio** - Galeria de projetos com hover effects
6. **Contato** - Formulário de contato com validação
7. **Footer** - Rodapé com links sociais

## 🚀 Como Usar

### 1. Clonar o Repositório
```bash
git clone https://github.com/davigoncalves15-cloud/Alura-1.git
cd Alura-1
```

### 2. Abrir no Navegador
Simplesmente abra o arquivo `index.html` em seu navegador favorito:
```bash
# No Windows
start index.html

# No macOS
open index.html

# No Linux
xdg-open index.html
```

### 3. Usando Live Server (Recomendado)
Se estiver usando VS Code:
1. Instale a extensão "Live Server"
2. Clique com botão direito em `index.html`
3. Selecione "Open with Live Server"

## 🔧 Customização

### Alterar Cores
Edite as variáveis CSS em `styles.css`:
```css
:root {
    --primary-color: #6c5ce7;
    --secondary-color: #00b894;
    /* ... mais variáveis ... */
}
```

### Adicionar Conteúdo
1. Edite o `index.html` para adicionar seus projetos e informações
2. Personalize o CSS conforme necessário
3. Adicione mais funcionalidades no `script.js`

## 🐛 Troubleshooting

### Imagens não carregam
- Verifique se os caminhos das imagens estão corretos
- Certifique-se de que o servidor está rodando

### Scripts não funcionam
- Abra o console do navegador (F12) e procure por erros
- Verifique se o arquivo `script.js` está sendo carregado

### Estilos não aplicam
- Limpe o cache do navegador (Ctrl+Shift+Delete)
- Verifique se o arquivo `styles.css` está vinculado corretamente
